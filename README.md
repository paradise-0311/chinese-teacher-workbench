## 更新部署

1. 先发布新的 Release，并附加 `site.zip`。
2. 将对应的 SHA-256、文件数及大小更新到主分支的 `manifest.json`。
3. 主分支清单或部署配置变更会自动部署；也可从 Actions 选择主分支手动运行。

工作流下载运行包，核验清单后部署至 Pages，遵循现有主分支部署规则。
