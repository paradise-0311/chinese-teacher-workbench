# 初中语文教研工作台 · 在线精简版

保留考情与精品题库查询，以及完整题干、阅读材料、题图和参考答案。

- 考情：146 套正式试卷。
- 题库：694 组、3086 道小题。
- 标准排版 Word 组卷使用离线工作台。
- 教学记录保存在当前浏览器，可备份与恢复，不自动跨设备同步。

在线运行文件使用压缩数据和按需加载，发布包约 24.7 MiB。原始 Word、PDF 和维护档案不随站点发布。

## 部署

发布 Release 并附加 `site.zip`，GitHub Actions 会核验 `manifest.json` 中的 SHA-256，解压并部署到 Pages。
更新时同时更新清单与站点资产。也可在 Actions 手动触发部署。
