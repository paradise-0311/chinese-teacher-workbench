## 更新部署

1. 先发布新的 Release，并附加 `site.zip`。
2. 将对应的 SHA-256、文件数及大小更新到主分支的 `manifest.json`。
3. 主分支清单变更会自动部署；部署配置调整后，可从 Actions 选择主分支手动运行。

工作流按清单版本下载 Release 运行包，核验大小、SHA-256 与文件数，在 HTTP 环境模拟项目子目录完成真实浏览器验收后部署至 Pages，并继续验收真实 HTTPS 网站。浏览器、Network、Console 和 CSP 记录保存在 Actions 的 browser-acceptance 附件中。部署遵循现有主分支规则。

验收覆盖完整数据契约、235 组原系统筛选对照、全部正文与题图资源、正文及答案预览、选题篮、教学记录备份恢复和考情回归。标准排版 Word 组卷保持离线版专属。
